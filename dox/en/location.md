## Location
---
The terrestrial location used for the calculation of the current event, if the event is dependent on a geographical point. 

It is generally a city name chosen by the user among the more than 3 million locations listed in the **Kaggle World Cities Database** freely available at `https://www.kaggle.com/datasets/max-mind/world-cities-database` and embedded locally in the application. 

If none of the proposed cities correspond or if one wishes to refine the terrestrial coordinates used, the user has the possibility to define the location to use by specifying its coordinates in latitude and longitude.
